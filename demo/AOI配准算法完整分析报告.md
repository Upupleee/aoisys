# AOI 模板-采样配准算法完整分析报告

> 面试导向整理：问题与难点 → 解决方案 → 达到的效果 → 产线可行性 → 图形类型的影响。
> 实验数据全部来自真实产线样本（weights222：模板 8152×15291 @0.5x = 4076×7645 工作分辨率，1582 个网格控制点，真值旋转 +0.229°、中心平移 (+2.55, +3.23)px）。
> 底层细节与全部实验记录见《AOI匹配与TPS实验汇总报告》。

---

## 0. 摘要（30 秒版本）

PCB 自动光学检测中，检测前必须把采样图精确配准到模板系，精度要求亚像素。难点是 PCB 高度重复的纹理让特征点法和相位相关都失效，加上蚀刻容差带来的平滑非刚性形变让全局单应在边缘区域不够用。我最终落地了**三遍粗到细 NCC + MAGSAC 单应 + 残差加权留出法 TPS（自动门控）**的方案：留出控制点残差中位 **0.21px**（半分辨率），无形变时自动退化为纯单应零额外开销，全链路 CPU **~4.7s**。另为无先验场景（换型、大偏移）验证了 FM→ECC 全局链路与 ALIKED+LightGlue 兜底两条通道。

---

## 1. 背景与问题定义

- **输入**：一张标准模板图与一张实拍采样图（同一区域，存在平移/微旋转/微缩放 + 蚀刻容差引起的平滑局部形变）。
- **输出**：把采样图翘回模板系的变换场（全局单应 + 局部形变补偿），供后续缺陷比对使用。
- **约束**：CPU-only（产线机台无 GPU）、整图 8K×15K 级别、要求亚像素配准精度、重复纹理/弱纹理区域大量存在。

---

## 2. 技术难点（面试重点：现象 → 根因 → 解决 → 验证）

### 难点 1：重复纹理让"教科书式"算法全部失效

**现象**：SIFT 426 对匹配 MAGSAC 后仅剩 21 内点且全部集中在顶部边框，单应直接退化；ORB 1583 对错配为主。检测器-描述子路线在这个数据上是结构性失效，不是调参问题。

**根因**：PCB 上几十个高度相似的电路单元，描述子最近邻匹配天然跨单元错配；ratio test 和 RANSAC 都救不回（内点数量不足以约束 8 自由度单应）。

**解决**：放弃特征点路线做主链路，改用**网格化 patch NCC**——在模板上铺规则网格，每个 patch 独立在采样图局部窗口内做归一化互相关搜索。NCC 的判别力来自 patch 内容本身而非"描述子距离"，配合**局部平面拟合一致性过滤**（3×3 网格邻居对位移场做一阶平面拟合，偏离面超过阈值的剔除）清掉跨单元误配。

**验证**：1582 网格点中一致性内点占绝对多数（连线图上红=被滤除、绿=内点一目了然）；ALIKED+LightGlue 作为对照倒是拿到了 80% 内点率——学习型描述子对重复纹理明显更稳，这也是后来把它留作兜底通道的原因。

### 难点 2：相位相关的"谐波峰"陷阱

**现象**：Fourier-Mellin（FFT 幅度谱 → log-polar → 相位相关）测旋转缩放都很好（自标定误差 <0.1°），但测平移时锁到 726px 的错误峰上（响应 0.032），而真实平移只有 ~3px。

**根因**：模板大量重复结构 → 平移相位相关面出现周期性谐波峰。更隐蔽的是：用**全局 ZNCC 验证**两个候选峰时，错误峰得分反而更高（0.41 vs 0.32）——因为真实对存在位移场与局部形变，全局相关被拉低，而"错误但自洽"的峰不受影响。**全局评分在这类数据上系统性偏好错误答案**。

**解决**：改用**分块局部 ZNCC 中位数**做验证——32px 小块在 ±8px 局部搜索窗内算相关，取全部块的中位数。局部块不受远处形变拖累，正确峰 0.872 vs 错误峰 0.823，判别裕度不大但方向正确。

**验证**：合成自标定实验（已知变换 (3°, 1.04, (20,−13))）先归因符号/量纲，再在真实对上确认选峰正确。这条链路（FM→ECC）最终做到与 NCC 主链路一致（med 0.08px），作为纯经典无先验备选。

### 难点 3：全局单应装不下真实形变 → TPS 但要防过拟合

**现象**：纯单应配准后整体残差 med 0.36px 尚可，但 P95 达 0.88px、误差热力图上有零星黄橙离群点、叠加图单元边缘残留红色错位——蚀刻容差是平滑的非刚性形变，单应 8 自由度表达不了边缘区域的偏差。

**解决**：**残差 TPS**——先拟合单应 H，再对 H 的残差场拟合薄板样条。关键设计是**防过拟合三件套**：
1. **加权留出法选 λ**：按 |H 残差| 加权评估（只在 H 失效的区域考核 TPS，避免大面积零形变区稀释 RMSE）；
2. **门控**：加权 TPS 须优于纯 H 5% 以上才启用，无形变产品零代价退化纯单应；
3. 只用一致性过滤后的训练点拟合，留出 20% 做诚实评估。

**验证**：合成形变实验 RMS 改善 1.4–2.3×、P95 改善 1.3–3.7×；真实对留出 med 0.36px(H) → 0.21px(H+TPS)。

### 难点 4：大图性能与内存（工程优化，最容易出彩的细节）

**现象与解决**（三个真实的坑）：
1. **TPS 全像素求值内存爆炸**：31M 像素 × 64 邻域 KD-tree 查询 → 14.9GB。改为 stride-8 求值 + 双线性放大（TPS 残差是低频场，stride 采样无损失）。
2. **OpenCV resize 半像素中心对齐陷阱**：stride-8 场直接 resize 后与全分辨率精确构造差 mean 20px——低分辨率网格的半像素中心错位被放大 8 倍。最终 H 和光流场全分辨率精确构造，仅低频 TPS 残差走 stride-8 + resize。
3. **非方形图 DFT 椭圆畸变**：4076×7645 图直接 FFT 测角误差比恰好等于长宽比 1.875——旋转在 DFT 索引空间不是圆。FFT 前必须裁中心正方形。

### 难点 5：评估口径本身会骗人

**现象**：Farnebäck 光流翘曲后重匹配残余 0.027px、ZNCC 0.91，看起来"完胜"TPS 的 0.214px；但它在留出控制点口径下是 0.590px，明显更差。

**根因**：光流的目标函数就是最小化外观差异——用"重匹配残余"评光流等于让它考自己出的卷子。TPS 是在**训练时没见过的留出点**上评估的。

**结论**：**算法对比必须固定在留出控制点口径**。这个认知后来也用在 FM 平移候选验证上（难点 2 本质是同一类问题：评估指标与算法目标函数耦合时会自我证实）。

### 难点 6：低 SNR 采样 + 重复阵列的全局定位（506s4e，三批数据交叉归因）

**现象**：第三批数据 506s4e 全链失败——先验内点率 0~9%、ECC/NCC/DL 兜底全部未过验收门。

**归因的排除法链条**（每步都有实验证据）：
1. 极性反转（用户指出的第一假设）→ 失败（内点率 0%）——排除极性；
2. CLAHE 增强 → std 仅 19.8→28.7，失败——**单调灰度变换不改变信噪比**，排除"对比度"；
3. 模板统计核对 → **三批模板均来自资料图纸转换且统计一致**（mean 150~186 / std 111~117）——推翻我自己此前"渲染图 vs 实拍"的归因，区分变量在采样侧；
4. 单元级目检 → 模板 U 形梳齿与实拍结构一一对应——排除图层错配；
5. 多单元平移一致性检验 → 三个单元各自匹配峰解出的平移互相矛盾（偏差 64~978px）——锁定根因：**低 SNR 采样（std=20）+ 8% 缩放差 + 重复单元阵列的单 patch 匹配多峰**。

**解决**：周期一致平移搜索——多单元各取 top-K 峰，按单元周期整数倍关系投票求共同平移（重复阵列全局定位的经典解法），解出后走现有矫正→ECC→NCC 链路；采样 SNR 本身转硬件侧（多帧累积/打光）。

**面试价值**：这是一个"用系统性排除法修正自己错误结论"的完整案例——每一步推翻都有实验证据，最终把失败归因从"想当然的域差"修正到"可操作的定位问题"。

## 4. 达到的效果

- **精度**：留出控制点残差 med **0.21px** @半分辨率（全分辨率等效 ~0.4px 换算需实机复测）；P95 从纯 H 的 0.88px 降至 TPS 后显著更低。
- **自适应**：门控使方案在"无形变"与"有容差形变"两类产品间自动切换，无形变零额外开销。
- **鲁棒链路完整**：有先验走 NCC 主链路；先验缺失/换型走 ALIKED+LG 兜底；纯经典兜底 FM→ECC（med 0.08px，与主链路一致）。
- **可视化与可解释性**：每个环节有独立验证图（连线图/叠图/热力图/自标定），出错可定位到具体环节——这在产线调试中比指标本身更值钱。

## 5. 产线可行性分析

| 维度 | 现状 | 评估 |
|---|---|---|
| **耗时** | 主链路 4.4s + TPS 0.25s @0.5x 全图；DL 兜底 ~12s；FM→ECC ~24s | 对 AOI 单工位节拍（秒~十秒级）可接受；主链路可再省（门控无形变时跳过 pass3） |
| **算力** | 纯 CPU，无 GPU 依赖 | 机台零硬件改动，部署成本低 |
| **内存** | TPS stride-8 后峰值可控；全分辨率精确构造 H/光流场 | 8K×15K 级别已在半分辨率验证，全分辨率需一次复测 |
| **鲁棒机制** | 一致性过滤 + MAGSAC + 门控 + 局部 ZNCC 验证，层层兜底 | 单环节失效不会静默传播到检测 |
| **已排除路线** | 形状匹配（含 +TPS）、SIFT/ORB、全局信息注入、全图二值化 | 均有实验记录，避免后续重复试错 |

**距离量产的明确清单**（不回避）：① 真实蚀刻容差样本到位后实机 A/B 终验；② 全分辨率耗时/内存复测；③ 各阈值（门控裕度 5%、NCC 门槛、过滤 10px、ratio 0.75）跨产品标定；④ FM 平移通道去先验化（top-K 多峰搜索替代"先验 t=0"第二候选）；⑤ DL 权重本地化（当前依赖 GitHub 镜像下载）。

**一句话结论**：算法侧已闭环，工程侧差一轮实机标定——这是"可以上产线验证"的状态，不是"还需要重新研究"的状态。

## 6. 不同图形对算法精度和稳定性有影响吗？

**有，而且是决定性的。** 本项目的每个算法结论背后都有图形类型的影子：

| 图形特征 | 对算法的影响 | 本项目实证 |
|---|---|---|
| **重复纹理**（相似单元阵列） | 特征点法跨单元错配（结构性失效）；相位相关锁谐波峰；全局验证指标系统性偏好错误答案 | SIFT 21 内点 H 退化、ORB 112 内点；FM 平移锁 726px 谐波峰；全局 ZNCC 0.41>0.32 选错峰 |
| **丰富孤立纹理** | 特征点法工作良好，学习型描述子尤其稳 | ALIKED+LG 80% 内点率、4050 内点，是唯一在重复纹理上仍然高内点率的特征路线 |
| **弱纹理/大面积均匀区** | patch 方差过低时 NCC 无判别力，必须拒识而非硬配 | NCC 一致性过滤对 std<4 的 patch 拒识；LoFTR（detector-free）在这类区域覆盖更均匀 |
| **高频线条/栅格** | NCC 亚像素精度好、光流友好；但对插值与半像素错位敏感 | resize 半像素错位被 stride 放大 → mean 20px 的教训 |
| **平滑非刚性形变** | 全局模型（单应）不足，需要 TPS/光流类形变场 | 纯 H 残差 P95 0.88px 且边缘区域超标，TPS 启用后留出 med 0.21px |
| **光照不均/对比度差异** | 全局阈值类预处理脆弱 | 采用 z-score 局部光照归一化，不做全图二值化 |

**由此得到的产线设计原则**：不存在"一个参数打天下"的算法，必须按图形类型**分层+门控**——NCC 网格为主干（对图形类型最钝感），门控决定要不要形变补偿，DL/FM 做无先验兜底，局部 ZNCC 做交叉验证。图形类型的影响应该作为**算法选择依据写进方案**，而不是指望调参消化。

**诚实边界**：以上结论来自单一 PCB 样本（高重复网格图形）。对其他图形类型（如大尺寸单电路、字符密集型、柔性板）的泛化未验证——这正是"阈值跨产品标定"待办存在的原因。

### 6.1 延伸：差分（缺陷比对）通道——三批数据暴露的难点、对策与现状

配准的下游是差分找缺陷。三种数据恰好构成差分难度的完整阶梯（同域同分辨率 → 同域跨分辨率 → 低 SNR 跨域），每批暴露一个独立难点：

| 难点 | 暴露数据 | 机理 | 对策 | 现状 |
|---|---|---|---|---|
| **差分基准的成像域** | 506s4e（采样低 SNR + 图纸模板跨域） | 图纸模板直接灰度差分=满屏伪差异（噪声/模糊/光照全不同） | **配准/检测通道解耦**：仿真模板只做配准；检测基准用良品统计基准（多张良品配准后运行均值+方差，z-score 判缺陷） | 架构确立，方案 A 原型待实现 |
| **分辨率/带宽不匹配** | 2652（8.5~10.8% 缩放差） | 矫正后采样经重采样，高频带宽与模板不一致 → 细线处系统差 | 差分前带宽对齐（等效模糊至同带宽） | 方案明确，待实现 |
| **配准残差传导** | weights222 | 配准误差直接进入差分残差，最小可检缺陷 ≥ 配准残差量级 | TPS 形变补偿 + 门控：留出 med 0.21px（w222）、0.10~0.91px（2652） | **已达成**——差分的精度前提在同域数据上成立 |
| 光照/对比度扰动 | weights222 | 全局阈值类预处理脆弱 | z-score 局部光照归一化 | 已实现 |
| 有效比对区域掩码 | 2652 / 506s4e | 稀疏板空白区无信号；渲染模板含板框/靶标/字符等非实物内容 | 内容掩码 + 有效区 ROI | 方案明确，待实现 |

**面试讲法**（一句话版）："配准决定差分的**下限**（配准误差混进差分残差，TPS 把它压到 0.21px），基准域决定差分的**可行性**（渲染模板做基准连差分都不成立，必须良品统计基准）——三批数据把这两条边界都实测标定了，所以我们把架构定成**配准通道与检测通道解耦**：配准走仿真模板，检测走良品统计。"

**诚实边界**：506s4e 的方案 A（仿真模板）与差分重构均为**已设计未实现**；2652 的带宽对齐同理。三批数据的差分现状是"同域料号全链就绪、跨域料号方案就绪"。

## 7. 面试表述建议

### 30 秒电梯稿

> "我在 AOI 项目里负责模板-采样配准，要求亚像素精度。最大的挑战是 PCB 重复纹理让特征点法和相位相关都失效，加上蚀刻容差的平滑非刚性形变，全局单应在边缘区域不够用。我做了一个三层方案：网格化 NCC 做主干，MAGSAC 单应加残差 TPS 做形变补偿并用门控防过拟合，DL 匹配做无先验兜底。最终留出控制点残差中位 0.21px，全链路 CPU 5 秒内，无形变时自动退化零开销。"

### 三个准备好的深挖故事（STAR 精简版）

1. **"系统会自我证实"**（最有含金量）：相位相关锁谐波峰 → 用全局 ZNCC 验证，错误峰反而得分更高 → 意识到评估指标与算法目标耦合时会自我证实 → 改分块局部 ZNCC 中位数 → 后来评光流时同样的坑再次出现（后配准口径光流"完胜"、留出口径反而差），从此固定留出控制点口径。**考察点：实验方法论。**
2. **"14.9GB 的教训"**：TPS 全像素求值内存爆炸 → stride-8 + resize → 但 OpenCV resize 半像素中心对齐被放大 8 倍，场错位 mean 20px → 最终"高频场精确构造、低频场采样近似"的分层策略。**考察点：工程优化能力。**
3. **"教科书算法为什么不行"**：SIFT 426 对匹配只剩 21 内点且全在边框 → 根因是重复单元的描述子混叠，是结构性的 → 换网格 NCC + 局部平面拟合一致性过滤 → 顺带发现学习型描述子（ALIKED）免疫这个问题，留作兜底。**考察点：失效分析能力。**

### 预判追问与答法

- *为什么不直接用深度学习？* → 数据量小、产线 CPU-only、可解释性要求高；DL 用在刀刃上（无先验兜底），主链路经典算法更可控。
- *0.21px 是真精度吗？* → 留出控制点口径、半分辨率；全分辨率与实机待终验，主动说边界。
- *换一个产品还能用吗？* → 机制上能（门控自适应），阈值要重标定，这是待办不是盲区。
- *图形有影响吗？* → 用 §6 的表格答：影响是决定性的，所以要分层+门控。
