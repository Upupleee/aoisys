# AOI 亚像素配准 · 面试 PPT 大纲

> 定位：10~15 分钟技术自述 + 问答支撑材料。主线是"**难点 → 解决方案 → 效果**"，每页配一张项目真实图（不放示意图，放实验产物最有说服力）。
> 每页给出：标题 / 要点 / 配图（标注文件）/ 讲法一句话 / 预判打断问题。
> 15 页为完整版；时间紧可砍第 10、13、14 页（标记 ○ 可选）。

**P1 封面**
- 标题：PCB AOI 模板-采样亚像素配准：从 9 类算法评测到产线方案落地
- 副信息：真实样本 8152×15291 @0.5x、1582 控制点、CPU-only
- 讲法："用一句话说结果：留出控制点残差中位 0.21px，全链路 CPU 4.7 秒。"

**P2 问题定义**
- 要点：输入（模板+实拍采样，平移/微旋转/微缩放+蚀刻容差非刚性形变）→ 输出（翘回模板系的变换场）→ 约束（亚像素、CPU-only、8K×15K 大图、重复纹理/弱纹理大量存在）
- 配图：`ov_ncc_h.png`（先展示"配准要解决什么"最直观）
- 讲法："左边没对齐是红色错位，配准就是把它变黄。"
- 预判：为什么必须亚像素？（残差混进缺陷比对 → 漏检/过杀）

**P3 挑战总览（先立靶子）**
- 要点：① 重复纹理 → 特征点法结构性失效；② 平滑非刚性形变 → 全局单应不够；③ 大图 → 内存/耗时；④ 无先验场景（换型）→ 主链路失效
- 讲法："四个挑战分别对应后面四个设计决策。"

**P4 方案总览（一张管线图）**
- 要点：三层——主干：三遍粗到细 NCC（256→256 锚定→96px）+ 局部平面拟合过滤 + MAGSAC 单应；形变层：残差加权留出法 TPS + 自动门控；兜底层：ALIKED+LightGlue（无先验）/ FM→ECC（纯经典无先验）
- 配图：自绘管线框图（三层+门控开关）
- 讲法："有先验走主干，形变由门控决定，先验丢了走兜底。"

**P5 难点①：重复纹理让教科书算法失效**
- 要点：SIFT 426 对匹配 → MAGSAC 后 21 内点全在顶部边框 → 单应退化；ORB 112 内点；根因：相似单元描述子混叠，结构性失效非调参问题
- 配图：`classical_feature_output/sift_matches.png`（错配连线）+ `ov_sift.png`（全红失效叠图）
- 讲法："注意这张叠图全红——单应已经退化到采样图完全没翘过去。"
- 预判：ratio test 为什么救不了？（滤歧义匹配，滤不了系统性混叠）

**P6 难点①解法：网格 NCC + 一致性过滤**
- 要点：网格化 patch 独立 ZNCC 搜索；3×3 邻居位移场一阶平面拟合，偏离面 >阈值剔除（容纳平滑形变大梯度）；结果 1582 网格点、med 0.36px
- 配图：`match_gallery_output/ncc_matches.png`（绿=内点红=滤除）
- 讲法："红线就是被过滤清掉的跨单元误配，集中在顶部边框——和 SIFT 内点的位置对上了。"

**P7 难点②：相位相关谐波峰 + "系统会自我证实"**
- 要点：FM 测旋转缩放 <0.1° 很好，测平移锁 726px 谐波峰（resp 0.032）；全局 ZNCC 验证选错峰（0.41>0.32）——真实位移场与形变拉低全局相关，错误但自洽的峰不受影响；合成自标定 (3°,1.04,(20,−13)) 先排除实现 bug
- 配图：自标定结果表 + 平移相关面示意图（若无存图用文字板式）
- 讲法："这个 case 教会我：评估指标和算法目标耦合时，系统会自我证实。"
- 预判：分块 ZNCC 裕度小（0.872 vs 0.823）敢用吗？（多约束叠加 + 先验范围 + 跨产品标定为待办）

**P8 难点②解法：分块局部 ZNCC 中位数**
- 要点：32px 块 ±8px 局部搜索取中位——局部块不受远处形变拖累；FM→ECC 链路最终 med 0.08px，与主链路一致，~24s 纯经典无先验
- 配图：`match_gallery_output/fm_ecc_matches.png`
- 讲法："这是留给'完全不许用 DL'场景的纯经典答案。"

**P9 难点③：全局单应装不下蚀刻容差**
- 要点：纯 H 残差 med 0.36px 但 P95 0.88px、热力图零星离群、叠加图边缘红边——平滑非刚性形变
- 配图：`hm_ncc_h.png`（黄橙离群点）+ `ov_ncc_h.png`（边缘红边，同页左右对比）
- 讲法："图上黄色异常点就是单应表达不了的地方。"

**P10 ○ 难点③方案细节：残差 TPS 防过拟合三件套**
- 要点：残差 TPS（只学非刚性部分）；加权留出法选 λ（只在 H 失效区域考核）；门控 5%（无形变零代价退化纯 H）；合成实验 RMS 1.4–2.3×、P95 1.3–3.7×，真实留出 0.36→0.21px
- 配图：`ov_ncc_tps.png`（边缘红边消退）vs `ov_ncc_h.png`
- 讲法："TPS 最大的风险是过拟合，三个机制各挡一类。"

**P11 难点④：大图工程优化（14.9GB → 0）**
- 要点：TPS 全像素求值 14.9GB → stride-8 + resize（低频场无损失）；踩中 OpenCV resize 半像素中心对齐 → 场错位 mean 20px → 高频场精确构造、低频场才采样近似；非方形 DFT 椭圆畸变（测角误差比=长宽比 1.875）→ FFT 前裁正方形
- 讲法："三个坑各对应一条分层优化原则：高频精确、低频采样、正方形化。"
- 预判：20px 错位怎么发现的？（可视化对照 + 已知正确实现交叉验证）

**P12 结果：9 类算法横向对比**
- 要点：对比表（NCC-H 0.36 / NCC+TPS 0.21 留出 / FM→ECC 0.59 / ALIKED+LG 0.74 / SP+LG 1.35 / LoFTR 0.96 / ORB 0.59 / SIFT 退化 / 光流稠密 1.11）；耗时列
- 配图：`overlay_heatmap_output/overlay_heatmap_overview.png`（9 行叠图|热力图总览）
- 讲法："一张表一张图墙，结论都在图上。"

**P13 ○ 评估方法论（防自我证实）**
- 要点：光流后配准口径 0.027px "完胜" TPS，留出口径 0.590px 反而差——光流目标函数即外观对齐，不能考自己出的卷子；全部对比固定留出控制点口径
- 讲法："如果只讲一页方法论，就是这一页。"

**P14 ○ 图形类型的影响**
- 要点：6 行表格（重复纹理/丰富纹理/弱纹理/高频栅格/平滑形变/光照不均 × 实证）；设计原则：图形类型写进算法选择依据，分层+门控，不指望调参
- 讲法："不存在一个参数打天下的算法。"

**P15 产线可行性与边界（收尾）**
- 要点：可行性（CPU 4.7s、零硬件改动、分层兜底、每环节可验证）；距量产清单（实机 A/B、全分辨率复测、阈值跨产品标定、权重本地化）；一句话收获（评估口径解耦 + 自相似数据上可视化独立参照更可信）
- 讲法："算法侧闭环，工程侧差一轮实机标定——这是'可以上产线验证'的状态。"（停顿，进问答）
